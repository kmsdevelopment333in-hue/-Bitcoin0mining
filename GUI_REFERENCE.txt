🎛️  CONTROL PANEL BUTTONS
═══════════════════════════════════════════════════════════════════════════

⛏ START MINING
   • Begins the mining process
   • Creates new block
   • Starts calculating hashes
   • Disables Start button
   • Enables Pause and Stop buttons

⏸ PAUSE / ▶ RESUME
   • Pauses mining temporarily
   • Can resume from same point
   • Button text toggles between "Pause" and "Resume"
   • Useful for short breaks

⏹ STOP
   • Completely stops mining
   • Current block progress is lost
   • Can start new block with Start button
   • Re-enables Start button

🔄 RESET
   • Clears all statistics
   • Resets blockchain to genesis block only
   • Resets counters to zero
   • Asks for confirmation first

⚙️  SETTINGS DROPDOWNS
═══════════════════════════════════════════════════════════════════════════

DIFFICULTY SELECTOR:
   ┌─────────────┐
   │ Very Easy   │ → 2 leading zeros (00...)
   │ Easy        │ → 3 leading zeros (000...) ✅ Recommended for beginners
   │ Medium      │ → 4 leading zeros (0000...)
   │ Hard        │ → 5 leading zeros (00000...)
   │ Very Hard   │ → 6 leading zeros (000000...)
   └─────────────┘
   • Can change anytime
   • New difficulty applies to next block
   • Does not affect current mining

CPU WORKLOAD SELECTOR:
   ┌─────────────┐
   │ Low         │ → 1,000 hashes/batch (~10% CPU)
   │ Medium      │ → 5,000 hashes/batch (~30% CPU) ✅ Default
   │ High        │ → 10,000 hashes/batch (~60% CPU)
   └─────────────┘
   • Controls CPU usage
   • Higher = faster mining but more heat
   • Can change anytime during mining

🎓 EDUCATIONAL FEATURES
═══════════════════════════════════════════════════════════════════════════

🔧 TAMPER TEST:
   What it does:
   • Modifies Block 1's data to "TAMPERED DATA - Educational Demo"
   • Recalculates Block 1's hash
   • Shows new hash in blockchain viewer
   • Block 2's "Previous Hash" no longer matches Block 1's hash
   • Chain becomes INVALID
   
   Purpose:
   • Demonstrates blockchain immutability
   • Shows how tampering is detected
   • Teaches why blockchain is secure
   
   How to use:
   1. Mine at least 1 block first
   2. Click "🔧 Tamper Test"
   3. Observe changes in Blockchain Viewer
   4. Click "✓ Validate Blockchain" to see error

✓ VALIDATE BLOCKCHAIN:
   What it does:
   • Checks every block in the chain
   • Verifies hash calculations are correct
   • Verifies all blocks are properly linked
   • Verifies all blocks meet difficulty requirement
   
   Shows one of:
   • "✓ Blockchain is valid" (green checkmark)
   • "✗ Block N: [error description]" (red X)
   
   Common errors after tampering:
   • "Block 1: Does not meet difficulty requirement"
   • "Block 2: Previous hash mismatch"
   
   How to use:
   • Click anytime to check chain integrity
   • Use after "Tamper Test" to see validation fail
   • Use after mining to confirm chain is valid

🔍 BLOCKCHAIN VIEWER TABLE
═══════════════════════════════════════════════════════════════════════════

Columns:

Block
   • Block number (0, 1, 2, 3, ...)
   • Block 0 is always Genesis block

Previous Hash
   • Hash of previous block in chain
   • Genesis block shows "0"
   • Truncated to first 16 characters + "..."

Nonce
   • The winning nonce value that produced valid hash
   • Shows how many attempts were needed
   • Formatted with thousands separators

Hash
   • The block's SHA-256 hash
   • Must start with N zeros (N = difficulty)
   • Truncated to first 16 characters + "..."

Difficulty
   • Number of leading zeros required
   • Genesis: 1
   • Mined blocks: 2-6 (based on your selection)

Timestamp
   • When block was mined
   • Format: YYYY-MM-DD HH:MM:SS

Status
   • Genesis: Block 0 only
   • Mined: Successfully mined block
   • Tampered: Data was modified after mining

Features:
   • Scrollable for many blocks
   • Auto-updates when new block is mined
   • Double-click any row to see full block details
   • Shows complete blockchain history

🎯 TYPICAL USAGE FLOW
═══════════════════════════════════════════════════════════════════════════

1. Application starts → GUI appears
2. Select difficulty → Choose "Easy" or "Medium"
3. Click "⛏ Start Mining" → Mining begins
4. Watch statistics → Nonce increments, hash changes
5. Block found! → Added to blockchain viewer
6. Demo coins increment → +6.25 per block
7. Continue mining → More blocks added
8. Try "🔧 Tamper Test" → See chain break
9. Click "✓ Validate Blockchain" → See error
10. Click "🔄 Reset" → Start over
11. Click "⏹ Stop" → Mining stops
12. Close window → Application exits
