STEP 1: VERIFY PYTHON IS INSTALLED
═══════════════════════════════════════════════════════════════════

Open Command Prompt or PowerShell and type:

    python --version

You should see: Python 3.7.x or higher

If not installed, download from: https://www.python.org/downloads/
(Make sure to check "Add Python to PATH" during installation!)

═══════════════════════════════════════════════════════════════════
STEP 2: NAVIGATE TO THE SIMULATOR FOLDER
═══════════════════════════════════════════════════════════════════

Open Command Prompt and navigate to where you saved the files:

    cd C:\bitcoin-mining-simulator

(Replace with your actual folder path)

═══════════════════════════════════════════════════════════════════
STEP 3: RUN THE SIMULATOR
═══════════════════════════════════════════════════════════════════

Simply type:

    python main.py

The GUI window will open immediately!

═══════════════════════════════════════════════════════════════════
QUICK USAGE GUIDE
═══════════════════════════════════════════════════════════════════

1. Select "Easy" or "Medium" difficulty
2. Keep CPU Workload at "Medium" (default)
3. Click "⛏ Start Mining"
4. Watch the statistics update in real-time!
5. Click "⏸ Pause" to pause mining
6. Click "⏹ Stop" to stop completely
7. Click "🔄 Reset" to clear everything

EDUCATIONAL FEATURES:
• 🔧 Tamper Test - See how changing data breaks the blockchain
• ✓ Validate Blockchain - Check if the chain is valid

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: "python is not recognized"
Solution: Reinstall Python with "Add to PATH" checked

Problem: GUI doesn't open
Solution: Check if tkinter is installed:
    python -c "import tkinter"

Problem: Mining too slow
Solution: Choose "Very Easy" or "Easy" difficulty

Problem: Computer getting hot
Solution: Reduce CPU workload to "Low", stop mining
