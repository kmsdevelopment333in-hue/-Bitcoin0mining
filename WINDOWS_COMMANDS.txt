HOW TO USE THE SIMULATOR
═══════════════════════════════════════════════════════════════════════════

1. SELECT DIFFICULTY:
   Click dropdown → Choose "Easy" or "Medium" for first time

2. SELECT CPU WORKLOAD:
   Keep at "Medium" (default) or choose "Low" for laptops

3. START MINING:
   Click "⛏ Start Mining" button

4. WATCH THE MAGIC:
   • Nonce increments rapidly
   • Hash changes every attempt
   • Hash Rate displays (e.g., 25,000 H/s)
   • When valid hash found → Block added to chain!
   • Demo Coins increment by 6.25

5. PAUSE IF NEEDED:
   Click "⏸ Pause" → Mining pauses
   Click "▶ Resume" → Mining continues

6. STOP MINING:
   Click "⏹ Stop" → Mining stops completely

7. RESET EVERYTHING:
   Click "🔄 Reset" → Clears all statistics and blockchain

8. TRY EDUCATIONAL FEATURES:
   • Click "🔧 Tamper Test" → See how changing data breaks the chain
   • Click "✓ Validate Blockchain" → Check if chain is valid
   • Double-click any block → See complete block details

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "python is not recognized"
SOLUTION:
    1. Reinstall Python from python.org
    2. ✅ Check "Add Python to PATH" during installation
    3. Restart Command Prompt
    4. Try: python --version

PROBLEM: GUI doesn't open / "No module named 'tkinter'"
SOLUTION:
    1. Reinstall Python
    2. Select "tcl/tk and IDLE" option during installation
    3. Complete installation
    4. Test: python -c "import tkinter; print('OK')"

PROBLEM: Mining is too slow
SOLUTION:
    1. Lower difficulty to "Easy" or "Very Easy"
    2. Increase CPU workload to "High"
    3. Close other programs
    4. Check Task Manager → Performance → CPU usage

PROBLEM: Computer getting hot
SOLUTION:
    1. ⚠️ STOP MINING IMMEDIATELY
    2. Lower CPU workload to "Low"
    3. Lower difficulty
    4. Ensure good ventilation
    5. Use cooling pad (laptops)
    6. Monitor temperature in Task Manager

PROBLEM: Hash rate is zero
SOLUTION:
    1. Click "⛏ Start Mining" first
    2. Wait 1-2 seconds for first update
    3. Check if mining is paused

PROBLEM: Window is too big / doesn't fit screen
SOLUTION:
    1. Your screen resolution may be too low
    2. Minimum required: 1200×800
    3. Try maximizing the window
    4. Or adjust Windows display scaling

MONITORING YOUR SYSTEM
═══════════════════════════════════════════════════════════════════════════

To monitor CPU and temperature:

1. Press: Ctrl + Shift + Esc
   → Opens Task Manager

2. Click "Performance" tab
   → See CPU usage percentage
   → See CPU speed

3. For temperature monitoring:
   → Task Manager (Windows 11) shows some temps
   → Or download: HWMonitor, Core Temp, etc.

SAFE TEMPERATURES:
    < 70°C: Excellent ✓
    70-80°C: Good ✓
    80-90°C: Warm ⚠️
    > 90°C: Too Hot! Stop mining immediately! 🛑
